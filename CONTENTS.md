# Folder and file guide

Start with [START-HERE.md](START-HERE.md). The core is portable instructions; optional software is not bundled.

| Folder | Purpose |
|---|---|
| skills | 12 discoverable core skills |
| specialist-library | 13 optional skills, opt-in |
| rules | One shared policy |
| agents | Three client-neutral role contracts |
| adapters | Client-specific notes and Claude import |
| templates | Copyable project and learning artifacts |
| scripts | Five standard-library Python helpers |
| memory | Schema, synthetic data and unapplied MCP examples |
| evals | 16 manual behavioral cases and fixture |
| model-profiles | Three model-scope profiles |
| setup | Client/WSL/phases/checks and software inventory |
| tests | Deterministic helper tests |
| docs/research | Original report and evidence |
