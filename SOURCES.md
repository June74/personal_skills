# Provenance and reuse

The skill bodies and helper scripts in this kit are newly authored for your requested workflow, informed by the inspected methods in the research report. No upstream executable, binary, model weight, full skill body or license-bearing source file is vendored here. The original report's ADAPT proposals have now been implemented as concise local instructions; they are not unmodified upstream distributions.

`sources.lock.json` records source references honestly: upstream revisions are not pinned because those files are not distributed. `kit-manifest.json` hashes the delivered local files. It provides integrity/change detection, not a signature or proof of trust. Refer to the audit for inspected paths, releases, mixed licenses and caveats. If later importing upstream code or prose, review its exact commit and preserve its license/notice; do not apply this kit's license to it.

The 13 optional skills are original, project-scoped procedures based on the report's recommendations; software remains separately licensed. Official documentation should be rechecked before dependency installation or live configuration. No upstream auto-updater is installed.
