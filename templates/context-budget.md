# Context and tool budget

Every session: tiny policy and project instructions; avoid duplicate rules.
Discoverable: 12 short skill descriptions; keep optional library outside automatic discovery.
When needed: relevant skill body, selected references/files, scoped tool results.
Memory: at most five snippets then two relevant records, initial target 500–1,000 tokens.
Agents: bounded question and compact evidence return; separate agents still consume tokens.
Manual artifacts: diagrams/voice/browser images consume model context only when shared.

Record client/model/version, task, skills loaded, tool calls, output sizes, reported tokens when available, elapsed time, correctness and learner comprehension. Missing measurements are unknown, not zero. MCP schemas may be deferred by the client; CLI output and screenshots are not free context. Compare on the same successful task rather than repeating a vendor's savings percentage.
