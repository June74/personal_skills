# Profiles tune scope, not safety

These JSON files are portable task guidance, not executable client model settings. Choose an available model manually after running representative cases. No API key, model purchase, provider routing or automatic delegation is configured.

Test unchanged skills on the candidate model first. Record client/provider/model/version, repository state, tool access and baseline. Compare correctness, tool behavior, honest failure, teaching, latency and cost; include images if needed. Change a profile before duplicating every skill. A lightweight model gets smaller tasks, not relaxed privacy or verification. Local models also need hardware/license/capability checks.
