# Evidence appendix — repository and implementation audit

Research cutoff: **2026-09-20**. This appendix records why the report's choices are supportable; it is not another installation list. It consolidates the skills, memory, and visual/voice research memos. Official client configuration and Agent Skills specification checks appear in the main report.

These were read-only inspections of documentation, release pages, manifests, selected skill bodies, and consequential helpers. Nothing was installed or executed. “Observed release” means the newest release visible in the inspected source; it is not a guarantee that no later release existed. `main`/`develop` links are mutable snapshots. Cached commit pages sometimes lagged release pages, so dated commits below establish activity, not current HEAD. A release date, push timestamp, and commit date are different evidence. Stars were not used as a quality score.

## Evidence from actual skills and helpers

- **TDD:** Matt's [actual skill](https://github.com/mattpocock/skills/blob/main/skills/engineering/tdd/SKILL.md), `tests.md`, and `mocking.md` emphasize vertical slices, public interfaces, and independent expected values. The current body postpones refactoring to review despite broader README terminology; the report proposes restoring small refactoring after green. This is a deliberate adaptation, not a verbatim upstream promise.
- **Debugging:** Superpowers' [skill](https://github.com/obra/superpowers/blob/main/skills/systematic-debugging/SKILL.md), root-cause reference, and [find-polluter.sh](https://github.com/obra/superpowers/blob/main/skills/systematic-debugging/find-polluter.sh) were read. The helper assumes Bash/npm, splits filenames on whitespace, and suppresses test errors. An environment-dump example needs replacement with redacted presence checks. No general Windows/Python suitability was inferred.
- **Skill evaluation:** Anthropic's [skill-creator](https://github.com/anthropics/skills/blob/main/skills/skill-creator/SKILL.md), aggregation/evaluation/description-loop scripts, schemas, and [viewer generator](https://github.com/anthropics/skills/blob/main/skills/skill-creator/eval-viewer/generate_review.py) were examined. Trigger evaluation invokes Claude CLI and writes temporary Claude commands, requiring adapters elsewhere. The viewer inserts generated JSON into HTML and may terminate the process occupying its port. Reported [escaping](https://github.com/anthropics/skills/issues/1788) and related viewer issues were not reproduced; this supports a simpler text/JSON review first, not a claim of a complete security audit.
- **Continuous learning:** ECC's [skill](https://github.com/affaan-m/ECC/blob/main/skills/continuous-learning-v2/SKILL.md), `hooks/observe.sh`, `scripts/instinct-cli.py`, and `agents/observer.md` expose real capture and background-analysis behavior. Recording and analysis are separate controls. The documented [native Windows observer limitation](https://github.com/affaan-m/ECC/issues/2489) matters; complete redaction was not established. Compound's [ce-compound](https://github.com/EveryInc/compound-engineering-plugin/blob/main/skills/ce-compound/SKILL.md) contributes a useful filter for verified, non-obvious lessons, but its full reference chain was not audited.
- **Design:** Anthropic's [frontend-design body](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md) is compact and script-free. Impeccable's shape/craft-floor/critique references and [launcher](https://github.com/pbakaus/impeccable/blob/main/.agents/skills/impeccable/scripts/impeccable) reveal a native engine, cached binary download, checksum check, and execution. Modern Impeccable cannot accurately be described as only Markdown prompts.
- **Specialists:** VoltAgent's [security-auditor](https://github.com/VoltAgent/awesome-claude-code-subagents/blob/main/categories/04-quality-security/security-auditor.md) specifies read/search tools; [architect-reviewer](https://github.com/VoltAgent/awesome-claude-code-subagents/blob/main/categories/04-quality-security/architect-reviewer.md) includes Write/Edit/Bash. Both inherit models. README generalizations do not substitute for exact frontmatter or client-enforced permissions.
- **Codebase visualization:** Understand-Anything's [skill](https://github.com/Egonex-AI/Understand-Anything/blob/main/understand-anything-plugin/skills/understand/SKILL.md) can install/build prerequisites, redirect worktree output, and launch many analyses. Its [incremental helper](https://github.com/Egonex-AI/Understand-Anything/blob/main/understand-anything-plugin/skills/understand/prepare-incremental.mjs) genuinely filters structural changes and writes JSON atomically. Node/pnpm/Python plus parser/dashboard dependencies distinguish it from a lightweight memory store.

Other inspected bodies support the teaching workflow without implying turnkey portability. Matt's [teach](https://github.com/mattpocock/skills/blob/main/skills/productivity/teach/SKILL.md) creates a multi-session course workspace and disables model invocation upstream; the proposed mentor skill is a smaller adaptation for everyday development. His [prototype](https://github.com/mattpocock/skills/blob/main/skills/engineering/prototype/SKILL.md), `UI.md`, and `LOGIC.md` distinguish visual alternatives from logic exploration and avoid default persistence. His codebase-design body was read, but its deeper design references were only identified. They should not be copied under an “audited” label.

Superpowers' [writing-plans](https://github.com/obra/superpowers/blob/main/skills/writing-plans/SKILL.md) includes implementation detail and framework handoffs that the proposed compact planning skill deliberately removes. The inspected requesting-code-review skill and reviewer template support independent review, while verification-before-completion concerns evidence for completion claims. This is why the report keeps those responsibilities distinct instead of activating several overlapping QA personas. These adaptations require authored files and evaluation; research did not produce an installed skill library.

Dependency inspection also distinguished optional capability from mandatory setup. K-Dense's scikit-learn examples do not require a scientific environment for ordinary application development. Handy's source-build manifest does not turn its compiler toolchain into a binary-install prerequisite. Penpot's inspected Compose file includes multiple services; calling it self-hosted does not make its maintenance equivalent to a static sketch. Unity's workflows reference is large and includes fresh-scene examples; those examples need scope checks before use on existing scenes. Blender skills from other repositories use connector-specific tool names, so their presence in a directory does not prove compatibility with the selected bridge.

The remaining portability work is concrete: translate client-specific frontmatter and invocation rules, verify discovery and routing, constrain permissions in each client, and test the same examples. Shared Markdown syntax alone establishes none of those behaviors. Likewise, separate context is useful for a bounded reviewer or codebase investigation, but an agent title does not establish isolation, durable memory, or authorization.

## Browser, design, voice, and editor versions

[Playwright CLI v0.1.21](https://github.com/microsoft/playwright-cli/releases), September 18, and [Playwright v1.63.0](https://github.com/microsoft/playwright/releases), September 4, were observed; both are Apache-2.0. The CLI's inspected [main manifest](https://github.com/microsoft/playwright-cli/blob/main/package.json) pins a 1.64 **alpha** Playwright build. That is not permission to upgrade a project's stable test dependency silently.

The actual [CLI skill](https://github.com/microsoft/playwright-cli/blob/main/skills/playwright-cli/SKILL.md), session and tracing references establish persistent/named sessions, file-backed output, screenshots, and scoped snapshots. Therefore “CLI is stateless” is false. Claimed token savings were not benchmarked. Trace files can contain headers, bodies, screenshots, and console data; saved regression tests remain distinct from exploratory agent browsing.

[Chrome DevTools CLI documentation](https://github.com/ChromeDevTools/chrome-devtools-mcp/blob/main/docs/cli.md) labels that interface experimental; the README documents usage statistics on by default and separate CrUX controls. No exact latest release was established. Agent-browser's [main manifest](https://github.com/vercel-labs/agent-browser/blob/main/package.json) showed 0.38.1 and Node >=24; browser-use's [main manifest](https://github.com/browser-use/browser-use/blob/main/pyproject.toml) showed 0.13.10, Python >=3.11, and MIT. These are source versions, not verified release tags.

Other dated checks: MIT [Handy v0.9.7, September 18](https://github.com/cjpais/Handy/releases); MIT [whisper.cpp v1.9.4, September 11](https://github.com/ggml-org/whisper.cpp/releases); MPL-2.0 [Penpot 2.17, July 8](https://penpot.app/release-notes/2-17-the-universal). Optional transcript cleanup sends text to the configured endpoint; local speech recognition alone does not establish cleanup privacy.

The [old Penpot MCP](https://github.com/penpot/penpot-mcp/blob/develop/README.md) was archived February 3 and moved into Penpot's monorepo; functionality was not abandoned. Unity MCP's inspected main manifests show 10.2.0, while README's dated 10.0.0 is June 30; latest published release was not independently established. Its MIT bridge license does not license Unity itself. Blender MCP's [manifest](https://github.com/ahujasid/blender-mcp/blob/main/pyproject.toml) shows MIT/2.0.0 and package rename `mcp-for-blender`; default telemetry consent and optional asset services require separate decisions.

## Limits carried into the recommendation

Direct dependency counts exclude transitives, models, services, and platform packages. No three-client concurrent-write test, Windows/WSL installation, restore test, latency/token measurement, malware scan, or complete supply-chain audit occurred. Reported bugs were evidence to investigate, not reproduced findings. Local storage still exposes retrieved text to whichever hosted coding model receives it. Proposed retention schemas, evaluation adapters, approval queues, and thin SQLite/MCP services are design work, not shipped integrations. The report's staged pilot and fallback to curated files follow from these limits.
