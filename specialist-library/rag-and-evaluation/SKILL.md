# Rag And Evaluation

Define task, privacy, latency and spending limits. Start with source IDs, simple chunking, lexical retrieval, cited context and one model call. Build representative labeled queries, unanswerable cases and hostile documents; evaluate retrieval separately from answer quality. Test tool/schema boundaries deterministically. Add embeddings, reranking, pgvector, an agent loop or orchestration only for measured baseline failures. Record model/version/dimensions and rebuild indexes when incompatible. Keep one SDK/provider boundary; verify local model capability instead of assuming equivalence. Report costs, failure cases and human judgments without fabricated scores.
