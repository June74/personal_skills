# Unity Workflow

Inspect editor/package versions, scenes and current unsaved work. Explain GameObjects, components and references when introduced. Checkpoint before scene/asset changes. Use minimal reproducible scenes and known rendering/physics settings for diagnosis. After edits, wait for compile, inspect console, run relevant edit/play tests and inspect screenshots/profiler. Prefer existing native tools; a matching community bridge is optional and must be scoped. Never replace an existing scene because a template creates one. Review asset/editor licenses separately; disable the bridge when finished.
