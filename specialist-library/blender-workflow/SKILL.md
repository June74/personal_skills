# Blender Workflow

Inspect Blender version, open scene and output requirements. Save/checkpoint first and explain object/mesh/material relationships. Prefer built-in bpy and saved scripts for deterministic generation, export and batch rendering. Use controlled camera/light/material settings and inspect results. A live bridge is optional; review arbitrary-Python authority, filesystem scope and its telemetry settings. For mcp-for-blender verify both environment and addon opt-outs; do not silently enable asset/cloud services. Preserve originals, inspect generated code and verify geometry/export conventions and asset licenses.
