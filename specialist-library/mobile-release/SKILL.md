# Mobile Release

Confirm target OS, framework, devices and distribution. Explain Android SDK/JDK/Gradle and macOS/Xcode requirements as applicable; WSL cannot supply Xcode. Use current official store documentation for account fees, identity/testing, target SDK, privacy, deletion, permissions and billing policies. Inspect included SDK behavior and signing-secret storage. Build/test on target devices, check crash/error paths, prepare store materials and staged rollback. Do not publish, enroll or pay without authorization. Retain a dated release checklist and provenance for declarations.
