# Release And Deployment

Inspect the actual target, runtime, lockfiles and deployment conventions. Establish build/start commands, required secrets, data migrations, health checks, logs, backups and rollback. Prefer one application and database before extra infrastructure. Test a production-like artifact locally; prepare an explicit release checklist. Separate preparation from authorized publication. Do not create accounts, bill services or deploy merely because a checklist mentions them. Record exact artifact/revision, checks, migration compatibility and recovery owner. Recheck provider limits and policies before launch.
